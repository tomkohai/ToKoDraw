## Installation Instructions
- [Installation Guide](https://tomkohai.github.io/ToKoDraw/installation.html)

1. Open Blender.
2. Go to **Edit → Preferences**.
3. Select the **Add-ons** section.
4. Click **Install…**.
5. Choose the file:  
   `ToKoDraw.zip`
6. Enable the addon in the list.

## Workflow and modes

## **Mode 1 — Handpainting a 3D Object**

Select your mesh, then click Create Material to apply it to the 3D object.
The TKD material is automatically created, and Texture Paint mode is activated with an Emission shader configured for painting. The Brush & Color Settings panel opens immediately to prepare the tool. Two layers are generated by default:

Canvas — the background layer. It cannot be deleted, but it can be hidden to make the object fully transparent when using the emission shader.

Layer 1 — the first painting layer, ready to use right away.

![Mode 1](/assets/tuto/modes/3D/3D.png)

![Mode 1](/assets/tuto/modes/3D/Mat.png)


**Mode CamView** 

The CamView Mode adds a dedicated panel that allows you to paint a 3D object through a 2D camera view, while maintaining full control over the object in Texture Paint. This mode provides intuitive navigation and precise transformation tools:

- 2D camera view for painting directly on a 3D object

- Full control of the object in Texture Paint

- Movement along the X / Y / Z axes

- Object rotation

- Zoom: Ctrl + middle‑mouse click

- Pan: Shift + middle‑mouse click

- Exit camera view: middle‑mouse click  or the camera icon

- Return to camera view: Numpad 0 or the camera icon

This mode combines the precision of a 2D view with the flexibility of 3D painting, offering a hybrid workflow that is particularly effective for touch‑ups, fine details, and perspective adjustments.

![Mode 1](/assets/tuto/modes/3D/camview.png)

1 - **Switch CamView on/off*

2 - **Show or hide the Transform panel*

3 - **Transform panel*

![Mode 1](/assets/tuto/modes/3D/move3Dobj.gif)



## **Mode 2 — Canvas 2D**  

In this mode, ToKoDraw transitions from 3D handpainting to a dedicated 2D painting workflow. After selecting an object and choosing Create Canvas, the user can decide whether the selected mesh should be hidden or removed, and define both the canvas size and its orientation (vertical or horizontal). Once validated, the addon generates a new plane as the 2D surface, creates a dedicated 2D camera, and automatically switches the viewport to camera view, allowing the user to paint just like in a traditional 2D software.

![Mode 2](/assets/tuto/modes/2D/2D.png)

![Mode 2](/assets/tuto/modes/2D/size.png)

As in Mode 1, the addon automatically creates the TKD material using an Emission shader configured for painting. Two layers are generated by default:

Canvas — the background layer, non‑deletable but hideable to make the plane fully transparent.

Layer 1 — the first active painting layer, ready to use immediately.

![Mode 2](/assets/tuto/modes/2D/canvas.png)


**Navigation on the canvas is intuitive:**

Ctrl + middle‑mouse click allows you to zoom in and out,

![Mode 2](/assets/tuto/modes/2D/zoom.gif)

Shift + middle‑mouse click allows you to pan the canvas within the view.

![Mode 2](/assets/tuto/modes/2D/move.gif)

The canvas can also be oriented and adjusted through the Transform panel, available inside the LayerForge panel.
Movements are performed along the axes:

X — lateral movement,

![Mode 2](/assets/tuto/modes/2D/xmove.gif)

Y — depth (forward / backward),

![Mode 2](/assets/tuto/modes/2D/ymove.gif)

Z — height (up / down),

![Mode 2](/assets/tuto/modes/2D/zmove.gif)


as well as rotation, allowing precise orientation of the painting surface.

![Mode 2](/assets/tuto/modes/2D/yrotate.gif)
